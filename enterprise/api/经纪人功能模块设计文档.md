# 经纪人功能模块设计文档

## 1. 企业端（需求发布与管理）

### 1.1 需求发布
- 企业填写需求表单（需求名称、类别、预算、截止日期、联系人方式等）
- 支持需求公开/仅认证经纪人可见

### 1.2 需求管理
- 企业查看已发布需求
- 修改需求
- 下架需求

---

## 2. 经纪人端

### 2.1 需求搜索与浏览
- **需求搜索**
  - 按关键词、行业、预算区间、地区筛选
- **需求列表**
  - 展示企业需求列表（标题、摘要、发布时间、企业信息级别）
  - 支持排序（最新、预算高、优先级高）
- **需求详情**
  - 展示详细需求信息
  - 支持立即联系 / 收藏需求

### 2.2 客户联系与管理
- **联系企业**
  - 经纪人点击“联系企业”后，系统自动记录联系行为
  - 企业可选择是否显示联系方式
- **联系过的企业管理**
  - 展示已联系过的企业列表
  - 展示企业信息、需求记录、最后联系时间
  - 支持添加备注（记录沟通情况）

### 2.3 客户标记（标签系统）
- **标签管理**
  - 经纪人可为客户打标签（重点客户、潜在客户、已合作、不活跃等）
  - 标签支持颜色标记
- **客户分类**
  - 可按标签过滤客户（重点跟进、已成交等）

---

## 3. 系统功能扩展

### 3.1 消息中心
- 企业与经纪人通过站内消息沟通
- 支持消息已读、未读状态

### 3.2 提醒功能
- 提醒经纪人对重点客户进行跟进
- 支持自定义提醒（如三天后再次联系）

### 3.3 数据分析
- 统计经纪人联系过的客户数、转化率
- 统计企业需求热度（被联系次数）

---

## 4. 数据库设计（简化）

### 4.1 企业需求表 `enterprise_needs`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| enterprise_id | int | 企业ID |
| title | varchar | 需求标题 |
| description | text | 需求描述 |
| budget | decimal | 预算 |
| category | varchar | 需求类别 |
| status | tinyint | 状态（发布/下架/完成） |
| created_at | datetime | 创建时间 |

### 4.2 经纪人客户联系表 `broker_contacts`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| broker_id | int | 经纪人ID |
| enterprise_id | int | 企业ID |
| need_id | int | 对应需求ID |
| status | varchar | 联系状态（待沟通/已沟通/成交/失效） |
| last_contact_at | datetime | 最后联系时间 |
| remark | text | 备注 |

### 4.3 标签表 `customer_tags`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| broker_id | int | 经纪人ID |
| enterprise_id | int | 企业ID |
| tag | varchar | 标签名称 |
| color | varchar | 标签颜色 |
