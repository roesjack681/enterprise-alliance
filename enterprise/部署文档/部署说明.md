# 后端服务部署说明

## 1，goserver 
    这个是go开发的底层服务，使用bt部署go网站运行即可，项目端口是3000

## 2，meilisearch
    搜索服务，毫米级响应.上传到服务器，使用PM2启动 ecosystem.config.js，如有调整配置项修改次文件即可。
    搜索服务初始化：需在api项目 放开入口函数 meilisearch 相关注释代码。

## 3，adminapi
    编译使用webpack。上传到服务器，pm2 启动管理

## 4，api
    编译使用webpack。需注意此项目一些库使用了c++模块，打包无法将模块打包进去，故部署有一些区别
    将package.json 上传到服务器，安装引入的模块。然后上传打包后的文件。pm2 启动管理。

## 5,数据库
    MySQL 8.4.5 要求8.0以上版本，将enterprise.sql.zip 使用bt面板上传导入。
    MongoDB 7.0.8 bt安装，配置到api项目的 config.ts中调整
    Redis 7.4.5
## 6，fileupload
    文件上传和服务。使用bt部署nodejs网站。

## 7，支付配置，短信配置
    相关配置在config.ts文件

# 测试访问
请使用自行配置的测试账户与本地服务地址。

# nginx 映射配置如下
    # api反向代理node服务
    location /api/ {
      rewrite ^/api/(.*)$ /$1 break;
      proxy_pass http://127.0.0.1:3009;
    }
    # adminapi反向代理node服务
    location /adminapi/ {
      rewrite ^/adminapi/(.*)$ /$1 break;
      proxy_pass http://127.0.0.1:9800;
    }
    
    # WebSocket 的反向代理
    location /socket.io/ {
        proxy_pass http://127.0.0.1:3009;  # 转发到 WebSocket 服务器的地址
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;        # 传递 Upgrade 请求头
        proxy_set_header Connection 'upgrade';         # 传递 Connection 请求头
        proxy_set_header Host $host;                    # 保持主机头
        proxy_cache_bypass $http_upgrade;               # 避免缓存代理
    }
